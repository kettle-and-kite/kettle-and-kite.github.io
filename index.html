Kettle & Kite Pinterest Integration: Privacy Policy

Effective date: October 13, 2026

Kettle & Kite is a small online shop that sells print-on-demand apparel and mugs on Etsy (kettleandkite.etsy.com). The Kettle & Kite Pinterest integration (“the integration”) is a private tool that the shop owner uses to publish the shop’s own product Pins to the shop’s own Pinterest business account and to measure how those Pins perform. It is not offered to, and cannot be used by, anyone else.

This policy explains what Pinterest data the integration accesses, what it keeps, why, and how that data is removed.

Pinterest permissions requested

When the shop owner signs in with Pinterest, the integration asks only for these permissions:

  • user_accounts:read: to read the account’s username, account type and business name, so the integration can confirm it is connected to the Kettle & Kite business account before it publishes anything;
  • boards:read and boards:write: to list the shop’s own boards and to create the shop’s own public boards;
  • pins:read and pins:write: to read the shop’s own Pins and to create Pins from the shop’s own product images.

The integration does not request access to Pinterest advertising, billing, catalogs or secret boards.

What the integration does with that access

  • It creates public Pins on the shop’s own account. Each Pin uses the shop’s own product image, a title, a description, alternative text, and a link to the matching Kettle & Kite listing on Etsy. The shop owner approves each Pin individually before it is published.
  • It creates the shop’s own boards to organize those Pins.
  • It reads back the boards and Pins it created, to confirm they were published correctly.
  • It reads Pinterest’s analytics for the Pins it created: impressions, saves, save rate, Pin clicks and outbound clicks.
  • It deletes a board or Pin only if the integration itself created it (for example, a test Pin), and only when the shop owner chooses to.

The integration does not access other Pinterest users’ accounts, profiles, boards, Pins, followers, comments or messages. It does not follow, comment, save, like or otherwise engage on anyone’s behalf. It does not scrape Pinterest, and it does not create advertisements.

What is stored, and where

  • Sign-in credentials. The app credentials and the access and refresh tokens that Pinterest issues are stored only on the shop owner’s own computer, in files that only the owner’s user account can read. They are never published, never placed in any code repository and never shared with anyone.
  • Account check. The connected account’s username, account type and business name, as read at sign-in, so the integration can refuse to publish to the wrong account.
  • Records of the shop’s own Pins. The identifiers of the boards and Pins the integration created, their publish times, and the analytics listed above. These are kept in the shop’s private business records to measure the shop’s own marketing.

No information about other Pinterest users is collected. Nothing is sold, rented or shared with third parties, and Pinterest data is not used for advertising.

Retention and deletion

  • Records of the shop’s own Pins and their analytics are kept for as long as the shop needs them for its marketing records. The shop owner can delete them at any time.
  • Access tokens expire automatically. The shop owner can revoke the integration’s access at any time in their Pinterest account settings, which stops all further access. The stored credentials and tokens are deleted from the owner’s computer when the integration is retired.
  • Any Pin or board the integration created can be deleted on Pinterest at any time.
